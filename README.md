# Casa Aia — Nova versão

Versão refeita para ficar mais próxima da identidade do projeto criado no Wix.

## O que já foi ajustado

- Cabeçalho minimalista com logo.
- Hero com a fachada real.
- Seção Essência e Imersão.
- 6 suítes em duas linhas de 3 no desktop.
- Experiência/jardim.
- Área de café da manhã preparada para receber fotos reais.
- Galeria com fotos reais.
- Localização.
- Área de reservas e formulário.
- Responsivo para celular e tablet.
- Animações suaves.

## Antes de publicar

1. Troque `5579999999999` pelo WhatsApp real.
2. Troque `contato@casaaia.com.br` pelo e-mail real.
3. Coloque o endereço oficial.
4. Confira qual foto corresponde a cada uma das 6 suítes.
5. Troque as 3 imagens provisórias da seção de café da manhã.
6. Conecte o formulário a um serviço de e-mail.
